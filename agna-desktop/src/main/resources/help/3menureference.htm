3. Menu reference

Items that compute something link to their explanation; follow the link

to read exactly what is calculated.

  • File: New Network...; Open Network; Open Sample Network & Case Study...; Merge Network...;

Save Network As... (the format list is documented in

File formats); Save Network; New From Chain...; Quit.

  • Edit: Cut / Copy / Paste / Delete / Select All (spreadsheet cell

editing).

  • Network:

- Title...; Add Nodes...; Delete Selected Node — bookkeeping, no

computation.

- Add Scalar... — shifts all off-diagonal values by a constant.

- Scalar Multiplication... — scales all off-diagonal values by a factor.

- Transpose — mirrors the matrix across the diagonal.

- Symmetrize... — makes the matrix symmetric; choose among 13 rules.

- Normalize (Binarize)... — dichotomise to 0/1, or threshold a weighted matrix.

- Dichotomize / Threshold Ties... — binary cut-off at custom threshold.

- Zero Diagonal (Remove Self-Loops) — resets all diagonal elements to 0.

- Set Diagonal to Value... — sets all diagonal elements to a constant.

- Extract Ego Network... — extracts the 1-hop or 2-hop ego subnetwork for an actor.

- Network Algebra (Combine Networks)... — element-wise addition, subtraction, intersection min, or Hadamard product.

- Reorder Sociomatrix / Sort Actors... — permute matrix by Name, Degree, Indegree, or Outdegree.

- Remove Outsiders — delete isolates.

- Renumber Nodes... — replaces names with numbers.

- Square Matrix — M×M, counting two-step walks.

  • Analysis:

- Full Analysis... — configurable execution of all analytical modules with presets.

- Sociometric & Basic... — macro parameters, density, dyad census, Newman assortativity, and valued/weighted metrics.

- Centrality & Prestige... — degree, geodesic (betweenness, closeness, fareness, Bavelas), prestige, and spectral centralities, plus the Freeman Centralization summary table.

- Distances & Geodesics... — geodesic matrix, eccentricity, diameter, and shortest paths.

- Clustering & Cohesion... — Watts-Strogatz local clustering, Newman transitivity, k-core, cohesion, maximal cliques, Louvain / Girvan-Newman community detection, and structural equivalence.

- Social Capital & Structural Holes (Burt)... — constraint, effective size, efficiency, and hierarchy.

- Connectivity & Articulation Points... — connected components, cut-vertices, and bridges.

- Triad & Dyad Census (Holland-Leinhardt)... — complete 16 MAN triad census and reciprocity.

- Spectral Centralities — Eigenvector (Bonacich), Bonacich Power c(alpha, beta), PageRank.

- Structural Archetypes Diagnostic... — test empirical networks against small-world, scale-free, homophily, and hierarchy theories.

- Hypothesis Testing (Null Models)... — Monte Carlo significance tests with Bernoulli Erdos-Renyi and degree-preserving configuration models.

- Analysis Advisor ("What Should I Compute?")... — beginner wizard mapping research questions to recommended analytical batteries.

- Algorithm Benchmarks... — empirical execution time and scaling benchmarks.

- Export Analysis Table... — export any displayed report table to CSV, TSV, JSON, or HTML.
