Analysis

 

All the analytic tools can be accessed through the Analysis menu in the Main Frame.

 

Basically, Agna can generate the following analyses:

  • general information (a Basic Description, some structural parameters: Diameter, Density, Cohesion)

  • information about the shortest paths in current network (Geodesic Matrix, Shortest Paths..., All Shortest Paths)

  • some node-level coefficients (four types of centrality coefficients and a few sociometric coefficients) together with their network-level aggregates and/or statistical descriptions
