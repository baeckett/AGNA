Comma-separated Files (*.csv)

 

A CSV  file will contain the sociomatrix plus the node names in the form of a matrix of g + 1 LINE-BREAK-separated rows, of g + 1 comma-separated values, where g is the number of nodes. The elements can be placed within quotation marks. The first element must be null.

 

Example

 

Open in a text editor the file Sociologists.csv, which is located in your Samples folder.

 

,Max Weber,Emile Durkheim,Karl Marx
Max Weber,0.0,1.0,1.0
Emile Durkheim,1.0,0.0,1.0
Karl Marx,1.0,1.0,0.0 

 

As you can see, it represents a network of 3 actors whose names are Max Weber, Emile Durkheim and Karl Marx and which are all connected among them.
