Network Viewer | Edge | Show Edge Value

 

Paints all edge values on the visual representation of the current network.

 

By default, edge values are invisible.

 

An edge's value is placed on that specific edge at a certain distance from the source-node, which can be set using Edge | Edge Value Position.

 

Edge values can be hidden using Edge | Hide Edge Value.
