Network Viewer | Node | Y-coordinate

 

Asks for a positive, non-zero integer representing the vertical coordinate (in pixels) of the selected node.

 

Any coordinate value which moved the selected node outside the image area would not be accepted.

 

The coordinate origin is the upper-left corner of the network image.

 

The reference point of the node is the upper-left corner of the node face.

 

The horizontal coordinate of a node can be set using Image | Node | X-coordinate.
