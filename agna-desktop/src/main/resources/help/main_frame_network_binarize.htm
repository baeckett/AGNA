Main Frame | Network | Binarize

 

Replaces all non-zero elements of current network's sociomatrix with 1. The value of all diagonal elements will be kept 0. A warning will be issued before this operation.

 

If the Network Viewer is activated, this change will affect both the sociomatrix and the visual representation of the current network.

 

Please note that no undo option is available.
