Visualizing Networks

 

To get a visual representation of the current network, simply choose View | Network Viewer from the Main Frame's menu.

 

A second frame will be activated, which will provide you with a simple network visual editor. You can save this image as a file on your hard disk, or insert it into your output file.

 

To customize the image, chose from the Image menu the command you wish: set the image width, scale the image, set the network layer (random vs. circular), change the title attributes of the image, specify the grid lines parameters, the node names, the background settings, the edge loyalty and the face settings for all nodes.

You can select a node by clicking inside its area (on its 'face'). To change the properties of the selected node, double-click it or chose from the Node menu the command you wish: set selected node's name, face, width and horizontal and vertical positions. You can also position your nodes on the screen by mouse drag-and-drop.

 

By default, clicking successively on two nodes will select an edge (if you don't need this and find it annoying, you can disable edge selection). The Edge menu allows you to set the connection value, the edge separation, edge color, the value of the most faded edge, the edge loyalty or the edge value position and color.

 

There are a few operations you can perform both in the sociomatrix editor (Main Frame) and the Network Viewer: adding nodes (double-click on the image outside a node area or by selecting Data | Add Nodes), removing outsiders, transposing network and symmetrizing network. Apart from these commands, the Network Viewer lets you clone, delete or isolate the currently selected node.

 

In large networks, finding a specific node is easy using the search tool located on a left panel:

 

 

To search for a node by name, type in the field the name or a fragment of a node name, then click Enter or press the search button. A list of results will be displayed. You can click on a node from that list and the corresponding node will be selected in the network. Double-click will show up the node settings dialog.
