Main Frame | Network | Remove Outsiders

 

Removes all isolated nodes from current network. The last two nodes of a network will never be deleted.

 

A node is called outsider or isolated when all its edge values are zero.

 

If the Network Viewer is activated, this change will affect both the sociomatrix and the visual representation of the current network.

 

Please note that no undo option is available.

 

In  the Network Viewer, you can call this operation by choosing Data | Remove Outsiders.
