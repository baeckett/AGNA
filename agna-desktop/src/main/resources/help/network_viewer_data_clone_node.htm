Network Viewer | Data | Clone Node

 

Clones the currently selected node and adds the clone to current network.

 

The incident edges of a clone will have the same values as the incident edges of the clone-source node.

 

This change will affect both the content of the visual network editor and the sociomatrix.

 

Please note that no undo option is available.
