Network Viewer | Image | Names | X-coordinate

 

Asks for a positive, non-zero integer representing the horizontal coordinate (in pixels) of a node's name relative to the position of that node on the image.

 

The vertical coordinate of the title can be set using Image | Names | Y-coordinate.

 

The coordinate origin is the upper-left corner of the node face.

 

Please note that the reference point of the title string is the lower-left corner of the string area.
