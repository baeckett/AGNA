Network Viewer | Edge | Most Faded Edge

 

Asks for an integer from 0 to 100 (%) representing the transparency of the least-value edge.

 

If value-loyalty is on, all edges will be rendered through a linear scale of transparency corresponding to their values and ranging from the Most Faded Edge's transparency down to zero.

 

By default, this value is set to 86 %.

 

Value-loyalty can be removed by selecting Edge | Remove Edge Loyalty and set on using Edge | Set Edge Loyalty from the Network Viewer's menu.
