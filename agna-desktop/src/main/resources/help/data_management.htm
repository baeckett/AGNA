Data Management

 

You can enter and edit network data either directly in Main Frame's sociomatrix grid or using the visual network editor (the Network Viewer).

 

Agna will treat all sociomatrix data as real numbers. The decision whether a network is binnary, weighted, directed or nondirected, will be taken by the application at run time. For example, if you wish to compute the indegree coefficients in current network, Agna will decide first whether the network contains weighted or binary data. In the first case, Agna will generate both the simple (binary) and the weighted versions of the indegree coefficient, whereas in the second case it will compute only the simple indegree coefficients.

 

The diagonal cells of the spreadsheet are not editable, as Agna does not allow a node to be connected to itself.

 

When entering data using the spreadsheet, move the cursor using the arrow keys or by mouse-clicking on a specific grid cell and type a new value corresponding to an edge weight. In the figure below, entering the value 1 at row 4 and column 2 will assign a new connection from node 4 to node 2 in current network. Entering a different value in the same cell, will assign a weighted connection to the same edge. 

 

   

 

You can make selections, copy, cut or paste ranges of data (eg, from a different application) in the spreadsheet.

 

By clicking a node label (the vertical header on the left of the sociomatrix spreadsheet), you can edit the name of that node. You can also rename all the nodes of the current network as numbers.

 

In the Network Viewer, you can modify the weight of an edge by successively clicking on two nodes and then setting the edge value (eg, by pressing Ctrl + E), like in this image:

 

   

 

Also, you can delete or clone an existing node, or add new nodes.

You can add a node simply by double-clicking on the image or using the menu and you can delete the selected node using the menu or by pressing the Delete key.

 

It is also possible to isolate or to clone a node or to remove all isolated nodes in your network.
