Main Frame | File | Save Network As

 

Saves current network data as a file on your hard disk after asking for a name and file type.

 

Three data file types are currently supported: Agna file format (*.agn), Comma-separated-values file format (*.csv) and tab-text file format (*.txt, *.text, *.dat).

 

Please note that no undo option is available.
