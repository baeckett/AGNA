Network Viewer | File | Insert In Output

 

Inserts current network image in the output file.

 

Your output file must have already been saved as a web page (*.htm or *.html ) in order to support any image insertion. If your current output file has not yet been saved as a web page, a warning message will be sent and you will then have the option to save it.

 

The HTML output will contain an inner image tag referencing to an automatically saved JPEG file. A new directory will be created on your hard disk, containing all the images of the current output file.

 

Please note that Agna will not delete any unused image existing on your hard disk and will not create temporary files either. Each time you select Insert In Output, a new image file will be saved in the output file's folder. Therefore, please make sure you always delete the files you don't need, as they may unnecessarily load up your disk space.
