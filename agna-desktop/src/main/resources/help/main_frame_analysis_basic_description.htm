The following information about the current network will be generated:

  • network type (directed vs. nondirected)

  • data type (binary vs. weighted)

  • number of nodes

  • number of outsiders (ie, isolate nodes)

  • number of edges (for symmetric networks, both directed and nondirected edge numbers are given)
