Main Frame | Network | Delete Selected Node

 

Removes  from the current network the node corresponding to the selected cell's column. If more than one cell is currently selected, the node corresponding to the left-most column of the selected range will be removed.

 

If the network has only two nodes, this command will be ignored.

 

If the Network Viewer is activated, this change will affect both the sociomatrix and the visual representation of the current network.

 

Please note that no undo option is available.
