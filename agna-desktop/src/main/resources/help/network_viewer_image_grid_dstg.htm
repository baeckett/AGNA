Network Viewer | Image | Grid | Don't Snap To Grid

 

Choose this option to disable the snap-to-grid function.

 

When enabled, snap-to-grid acts as a "gravity force" during the drag-and-drop operations, constraining nodes to take positions close to the grid lines and thus helping you to align them easier.

 

You can enable snap-to-grid using Image | Grid | Snap To Grid.
