Statistics

 

Every time an index is computed at node-level, Agna generates a set of statistical parameters describing the distribution of that index.

 

Specifically, the statistics table is produced for the following indexes: eccentricity, nodal degree, indegree, outdegree, emission degree, reception degree, determination degree, sociometric status, Bavelas-Leavitt centrality, closeness centrality, fareness centrality and betweenness centrality.

 

If there are g values of an index w, then the statistical parameters are computed as follows:

  • The Maximum is the greatest value of the index;
