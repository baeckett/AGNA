Main Frame | Network | Symmetrize

 

Asks for the selection of a symmetrization criterion and converts current sociomatrix to a symmetrix matrix (and thus the current network to a non-directed network). Specifically, all paired elements (x[i,j] and x[j,i]) will be made equal according to one of the following  criteria:

  • Maximum: the maximum value of the two will be chosen;

  • Minimum: the minimum value of the two will be chosen;

  • Maximum Non-Zero: the maximum value of the two will be chosen; if one of the elements is zero, the other one will be chosen;

  • Minimum Non-Zero: the minimum value of the two will be chosen; if one of the elements is zero, the other one will be chosen;

  • Below Diagonal: the element located below the sociomatrix' diagonal will be chosen;

  • Above Diagonal: the element located above the sociomatrix' diagonal will be chosen;

  • Below Diagonal Non-Zero: if non-zero, the element located below the sociomatrix' diagonal will be chosen; otherwise, the element located above the diagonal will replace both;

  • Above Diagonal Non-Zero: if non-zero, the element located above the sociomatrix' diagonal will be chosen; otherwise, the element located below the diagonal will replace both; 

  • Sum: the arithmetical sum of the two paired elements will replace both (even if these elements were already equal);

  • Product: the arithmetical product of the two paired elements will replace both (even if these elements were already equal);

  • Product Non-Zero: the arithmetical product of the two paired elements will replace both (even if these elements were already equal); if one of the elements is zero, the other one will be chosen;

  • Arithmetical Mean: the arithmetical mean of the two paired elements will replace both.

  • Geometrical Mean: the geometrical mean of the two paired elements will replace both.

If the Network Viewer is activated, this change will affect both the sociomatrix and the visual representation of the current network.

 

Please note that no undo option is available.

 

In the Network Viewer, you can call this operation by choosing Data | Symmetrize.
