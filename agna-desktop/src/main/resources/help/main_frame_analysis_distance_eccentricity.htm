Main Frame | Analysis | Distance | Eccentricity

 

Computes the eccentricity of each node in current node. The eccentricity of a node is the length of the longest geodesic path originating in that node.

 

A set of statistical parameters (minimum, maximum, sum, mean, variance, standard deviation, absolute entropy, maximum entropy and relative entropy) will be computed as well for the eccentricity distribution.

 

A geodesic path is a path between two given nodes that has the shortest possible length.

 

The length of a path is the number of edges that comprise that path (weighting information will be ignored: what matters here is only the existence/absence of connections among nodes).
