Agna Data File Format (*.agn)

 

AGN files are text files that contain full information about the networks created using Agna. They are automatically generated by the application at save time, but you can edit them manually as well.

 

The AGN file format itself does not fall under Agna's general Copyright (this means that other applications are free to export networks in this format).

 

A Simple Example

 

Here is an example of an AGN file in Version 2.1. We will create a 3 nodes network where each node is connected to each other. The node names will be: Max Weber, Emile Durkheim and Karl Marx. Using a basic text editor (such as Notepad on Windows), open the file Sociologists.agn, which is located in your Samples folder. Or, you could type the following text by yourself and save it on you hard disk under the same name:

2.1

This is a fictional network

 

Network Name

Fathers of Sociology

Network Size

3

no

0

1

1
1

0

1
1

1

0
End Network Matrix

Node Names
Max Weber
Emile Durkheim
Karl Marx
End Node Names

 

This is the basic structure of an AGN file. As you can see, it consists of a list of elements, starting with the header Agna Data File  (which is required). The list contains tags (both paired and unpaired tags) and values.

 

These elements are separated by TAB or LINE BREAK (actually, any combination of characters with ASCII code below 32 would do). For this reason, tags and values cannot contain TABs or LINE BREAKs. Blanc spaces are, however, allowed (for example, a node can be named Emile Durkheim).

 

Tags can be mentioned across the file anywhere and in any order you wish. The next element following an unpaired tag must always be its value. Paired tags usually enclose a list of elements, such as the list of node names.

 

Agna will tacitly ignore any text that is not a tag or is not obviously a tag value (such as:   This is a fictional network  in our example).

 

Please note that tag names are case sensitive!

 

There is virtually no limit as to the length of a value string.

 

Try now and open the file Sociologists.agn using Agna (File | Open Network) and check the names and the sociomatrix. 

 

Required tags

 

Here is the list of the tags that must be present in any AGN file:

 

Tag name:    Version

Pair:    --

Value:    Application Version, eg: 2.1

Note:    Useful for backwards compatibility

 

Tag name:    Network Name

Pair:    --

Value:    Name of network, eg: Fathers of Sociology

Note:    A string

 

Tag name:    Network Size

Pair:    --

Value:    Size of network, eg: 3

Note:    An integer value

 

Tag name:    Has Viewer

Pair:    --

Value:    yes or  no

Note:    yes if file contains graphical information; no if file contains no graphical information

 

Tag name:    Network Matrix

Pair:    End Network Matrix

Value:    A list of elements separated by TAB or LINE BREAK or combinations of them 

Note:    These elements represent the network's sociomatrix. Their number must be exactly g x g, where g is the value of the Network Size tag. They can be integer, real, positive or negative numbers. Diagonal elements must be 0  or Agna will tacitly set them to 0.

 

Tag name:    Node Names

Pair:    End Node Names

Value:    A list of elements separated by TAB or LINE BREAK or combinations of them 

Note:    These elements are strings representing the network's node names. Their number must be exactly g, where g is the value of the Network Size tag.

Graphical tags

 

So, in order to provide graphical information, your AGN file must set the Has Viewer tag to   yes and provide a list of tags about how to render your network visually. If an AGN file does not provide graphical information, Agna will use the default preferences to render the network.

 

Here is the list of the tags related to a network's graphical information and to Visual Network Editor's preferences:

 

Tag name:    STG Enabled

Pair:    --

Value:    yes or  no

Note:    Enable/Disable the snap-to-grid function. Check out the meanings of  yes and  no.

 

Tag name:    Title Visible

Pair:    --

Value:    yes or  no

Note:    Image title's visibility option. Check out the meanings of  yes and  no.

 

Tag name:    Edge Value Visible

Pair:    --

Value:    yes or  no

Note:    Edge value's visibility option. Check out the meanings of  yes and  no.

 

Tag name:    Print Names

Pair:    --

Value:    yes or  no

Note:    Node names' visibility option. Check out the meanings of  yes and  no.

 

Tag name:    Grid Enabled

Pair:    --

Value:    yes or  no

Note:    Grid's visibility option. Check out the meanings of  yes and  no.

 

Tag name:    Face Visible

Pair:    --

Value:    yes or  no

Note:    Node faces' visibility option. Check out the meanings of  yes and  no.

 

Tag name:    Allow Edge Selection

Pair:    --

Value:    yes or  no

Note:    Enable/Disable the edge selection function. Check out the meanings of  yes and  no.

 

Tag name:    Color Fidelity

Pair:    --

Value:    yes or  no

Note:    Enable/Disable the color fidelity (or color loyalty) function. Check out the meanings of  yes and  no.

 

Tag name:    Area Width

Pair:    --

Value:    Size of image, eg: 200

Note:    An integer value. Meaning.

 

Tag name:    Selected Node

Pair:    --

Value:    Index of selected node (end-node), eg: 1

Note:    An integer value from 0 to g-1. -1 if none.

 

Tag name:    Second Selected Node

Pair:    --

Value:    Index of second selected node (start-node), eg: 1

Note:    An integer value from 0 to g-1. -1 if none.

 

Tag name:    Names X

Pair:    --

Value:    Horizontal names coordinate (px), eg: 3

Note:    An integer value. Meaning.

 

Tag name:    Names Y

Pair:    --

Value:    Vertical names coordinate (px), eg: -2

Note:    An integer value. Meaning.

 

Tag name:    Title X

Pair:    --

Value:    Horizontal title coordinate (px), eg: 13

Note:    An integer value. Meaning.

 

Tag name:    Title Y

Pair:    --

Value:    Vertical title coordinate (px), eg: 15

Note:    An integer value. Meaning.

 

Tag name:    Separator

Pair:    --

Value:    Edge separation, eg: 0

Note:    An integer value. Meaning.

 

Tag name:    Edge Value Position

Pair:    --

Value:    Edge value position, eg: 30

Note:    An integer between 0 and 100. Meaning.

 

Tag name:    Grid Transparency

Pair:    --

Value:    Grid transparency, eg: 25

Note:    An integer between 0 and 255. Meaning.

 

Tag name:    Max Transparency

Pair:    --

Value:    Edge maximum transparency, eg: 35

Note:    An integer between 0 and 255. Meaning.

 

Tag name:    Background Image X

Pair:    --

Value:    Background image horizontal coordinate, eg: 0

Note:    An integer. Meaning.

 

Tag name:    Background Image Y

Pair:    --

Value:    Background image vertical coordinate, eg: 0

Note:    An integer. Meaning.

 

Tag name:    Background Image Width

Pair:    --

Value:    Background image width, eg: 0

Note:    An integer. Meaning.

 

Tag name:    Background Image Height

Pair:    --

Value:    Background image height, eg: 0

Note:    An integer. Meaning.

 

Tag name:    Grid Space

Pair:    --

Value:    Distance between any two grid lines (px), eg: 40

Note:    A positive integer value. Meaning.

 

Tag name:    Edge Value Color

Pair:    --

Value:    Edge value color, eg: #00bfa6

Note:    An RGB hex code. Meaning.

 

Tag name:    Grid Color

Pair:    --

Value:    Grid color, eg: #0ad20a

Note:    An RGB hex code. Meaning.

 

Tag name:    Text Color

Pair:    --

Value:    Node names color, eg: #404040

Note:    An RGB hex code. Meaning.

 

Tag name:    Title Color

Pair:    --

Value:    Title color, eg: #404040

Note:    An RGB hex code. Meaning.

 

Tag name:    Background Color

Pair:    --

Value:    Background color, eg: #ffffff

Note:    An RGB hex code. Meaning.

 

Tag name:    Arrow Color

Pair:    --

Value:    Edge color, eg: #89a0a0

Note:    An RGB hex code. Meaning.

 

Tag name:    Background Image File

Pair:    --

Value:    Background Image Path, eg: C:\Picture.jpg  (on Windows)

Note:    Full or relative path. - if none. Meaning. Current versions support only platform-specific paths.

 

Tag name:    Node Faces

Pair:    End Node Faces

Value:    A list of image paths separated by TAB or LINE BREAK or combinations of them 

Note:    Full or relative paths. - if none. Their number must be exactly the value of the Network Size tag. Meaning. Current versions support only platform-specific paths.

 

Tag name:    Node Coordinates

Pair:    End Node Coordinates

Value:    A list of elements separated by TAB or LINE BREAK or combinations of them.

Note:    Integers representing horizontal coordinate, vertical coordinate and face width (in this order) for each node. The number of elements must be exactly the value of the Network Size tag multiplied by 3.
