Main Frame | Analysis | Distance | All Shortest Paths

 

Generates a list of all possible paths of minimum length between all pairs of nodes in current network.

 

The length of a path is the number of edges that comprise that path (weighting information will be ignored: what matters here  is only the existence/absence of connections among nodes).
