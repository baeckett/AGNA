Main Frame | File | Open Output

 

Loads an existing output file into output area.

 

An output file can be either a text file (*.txt) or a web page (*.htm, *.html).

 

Please note that opening a text file will change output area's default mode of working, therefore this option is not recommended. If you wish to insert data into your output use Paste instead.
