Managing Output Files

 

Once there is some text in the output area, you can save it as an HTML file on disk so that you can view it and print it using an ordinary web browser or load it back into Agna's output area.

 

Agna offers a few editing capabilities for output files as well: copying, deleting, making selections and pasting. Still, please note that these functions are very limited, as Agna was not designed to be a web page editor.
