Text Tab-separated Files (*.txt, *.text, *.dat)

 

A text network file will contain the sociomatrix only, in the form of a list of g x g elements, where g is the number of nodes. The elements can be separated by TAB, LINE BREAK or any combination of these.

 

Example

 

Open in a text editor the file 4 full.txt, which is located in your Samples folder.

 

0
2
3
4

5
0
7
8

9
10
0
12

13
14
15
0

 

As you can see, it contains a list of 16 integers, which comprise the sociomatrix of a 4 nodes network, where each node is connected to each other. The values represent the connection weights.
