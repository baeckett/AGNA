Main Frame | View | Network Viewer

 

Opens up a second frame (the Network Viewer) containing a visual network editor.

 

While opening and closing the Network Viewer will not affect the status of this application's Main Frame, be aware that opening the visual network editor will use up some extra resources. Therefore, it is not recommended to open the Network Viewer before launching certain memory-consuming operations such as All Shortest Paths, especially when dealing with large networks.
