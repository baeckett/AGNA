Main Frame | Network | Title

 

Asks for a new title and assingns it to the current network.

 

The network title is different from the name of the file and is displayed by default as a title on the visual representation of the network. The title can be displayed using Network Viewer's Show Title option from the Image | Title menu.

 

By default, a network will have the title 'New Network'.
