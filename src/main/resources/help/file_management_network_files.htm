Managing Network Data Files

 

The File menu allows you to

  • create a new empty network,

  • open an existing network from disk,

  • create a new network from a chain file, or

  • save the current network as a file.

At present, the following file formats are supported for storing/retreiving network data:

  • Agna Data Format (*.agn) 

  • Comma Separated Values (*.csv)

  • Text tab-separated (*.txt, *.dat, *.text)
