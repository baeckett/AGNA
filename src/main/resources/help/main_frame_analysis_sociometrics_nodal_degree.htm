Main Frame | Analysis | Sociometrics | Nodal Degree

 

Can be applied to nondirected (ie, symmetric) networks only.

 

Computes the nodal degree and the weighted nodal degree (in the case of weighted data only) of each node in current network. Also, computes two relative versions of both weighted and binary nodal degrees: The * version is a relative index to g - 1, whereas the ** version is relative to g, where g is the size of the network.

If the current network contains weighted data, both the weighted and unweighted nodal degrees will be computed. A set of statistical parameters (minimum, maximum, sum, mean, variance, standard deviation, absolute entropy, maximum entropy and relative entropy) will be computed as well for the nodal degree distributions.
