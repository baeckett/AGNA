Network Viewer | Image | Image Width

 

Asks for a positive integer representing the new image width (in pixels) and scales the whole network image to the new width. Changing the image width will proportionally rearrange all nodes.

 

If you entered a value smaller than 32, this command would be tacitly ignored.

 

As the network image is always a square, the image height can't be set manually.

 

Please note that no undo option is available.
