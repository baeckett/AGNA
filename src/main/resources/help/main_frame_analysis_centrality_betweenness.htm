Main Frame | Analysis | Centrality | Betweenness

 

Computes the Betweenness index of centrality for each node in current network.

 

For a given node i, this index is computed as the sum of the ratios of the number of geodesic paths between all possible pairs of nodes j and k involving node i to the number of all geodesic paths between j and k:


   


where g is the size of the network, is the total number of geodesic paths from node j to node k and is the number of geodesic paths from node j to node k involving node i.

 

A geodesic path is a path between two given nodes that has the shortest possible length. The length of a path is the number of edges that comprise that path (weighting information will be ignored: what matters here is only the existence/absence of connections among nodes).

 

The Freeman General Centrality index and a set of statistical parameters (minimum, maximum, sum, mean, variance, standard deviation, absolute entropy, maximum entropy and relative entropy) will be computed as well for the Betweenness distribution.
