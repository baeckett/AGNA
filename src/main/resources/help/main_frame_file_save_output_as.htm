Main Frame | File | Save Output As

 

Saves the current output information as a file on your hard disk after asking for a name and file type.

 

Two data file types are currently supported: web page (*.htm, *.html) and text file (*.txt).

 

Please note that:

 

   1. no undo option is available;

   2. Agna's output area is just a very basic html generator, not a web page maker.
