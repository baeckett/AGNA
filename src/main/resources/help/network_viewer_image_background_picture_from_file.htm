Network Viewer | Image | Background Picture | From File...

 

Loads an image file from disk and paints that image as a background of the current network image.

 

The background picture can be destroyed using the Image | No Background Picture command.

 

You can also use a plain color as background for your network representation, by selecting Image | Background Color.
