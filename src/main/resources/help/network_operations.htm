Network Operations

 

Several operations can be applied to the currently open network:

  • adding a scalar value to all sociomatrix elements;

  • multiplying by a scalar value all sociomatrix elements;

  • transposing the network's sociomatrix;

  • symmetrizing the network's sociomatrix;

  • binarizing the network's sociomatrix;

  • multiplying the sociomatrix by itself.
