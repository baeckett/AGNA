Computes the Fareness index of centrality for each node in current network.

where g is the size of the network and is the geodesic distance from node i to node j.

 

A geodesic path is a path between two given nodes that has the shortest possible length. The length of a path is the number of edges that comprise that path (weighting information will be ignored: what matters here is only the existence/absence of connections among nodes).

 

The Freeman General Centrality index and a set of statistical parameters (minimum, maximum, sum, mean, variance, standard deviation, absolute entropy, maximum entropy and relative entropy) will be computed as well for the Fareness distribution.
