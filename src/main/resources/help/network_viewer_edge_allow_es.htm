Network Viewer | Edge | Allow Edge Selection

 

Selecting this option, edge selection will be allowed in the visual network editor. That is, each time you will successively click on a two nodes, the edge corresponding to the connection from the first to the second node will be selected.

 

Once you have selected an edge, you can change its value (Edge | Edge Value).

 

Selecting and unselecting edges will not affect node selection.

 

You can disallow edge selection by choosing Edge | Disallow Edge Selection.
