.TH AGNA 1 "September 2026" "Agna 2.1.3" "Agna CLI Manual"
.SH NAME
agna \- social network analysis command line tool
.SH SYNOPSIS
.B agna
.RI command " [" options "] [" file ]
.br
.B agna
\-\-help
.br
.B agna
\-\-version
.SH DESCRIPTION
.B agna
is the command line interface of the Agna social network analysis
suite.  It runs the Agna engine headlessly: no desktop, no windowing,
everything pipable and scriptable.  A file argument of
.B \-
reads agn text from standard input (override with
.BR \-\-in\-format );
an output of
.B \-
writes to standard output (text formats only, use
.B \-\-out\-format
to choose which).
Input formats: agn, txt, csv, net, xls, xlsx, graphml, gml, graphson.
Output formats: agn, txt, csv, net, graphml, gml, graphson, xls.
Exit status: 0 on success, 1 on usage errors, unknown commands, unknown
metrics, unreadable files or exceptions.
.SH COMMANDS
.TP
.B version, \-\-version
Print the version and exit.
.TP
.B info FILE
Print a network summary: name, number of nodes, number of edges, basic
description.
.TP
.B analyse FILE [\-\-all|NAME...|cliques:N] [\-\-out FILE]
Run the analysis battery.  Without a NAME the full battery runs
(same as
.BR \-\-all ).
Available analyses: basic, density, cohesion, nodal, indegree,
outdegree, emission, reception, determination, status, geodesics,
open-chain, eccentricity, diameter, bavelas, closeness, fareness,
betweenness, prestige, cliques (size via cliques:N), full.
With
.B \-\-out FILE
the report is written to FILE instead of standard output.
.TP
.B convert IN OUT [\-\-in-format F] [\-\-out-format F]
Convert a network from one format to another; the format is inferred
from the file extension.  \-\-in-format overrides the input inference
(needed when IN is
.BR \- ),
\-\-out-format overrides the output inference.
.TP
.B transform IN OUT \-\-op OP [\-\-in-format F] [\-\-out-format F]
Apply a network operation and save the result to OUT (the input file
is never modified).  Operations:
.BR transpose ,
.BR symmetrize-max ,
.BR symmetrize-sum ,
.BR symmetrize-below ,
.BR normalize-binary ,
.BR normalize-threshold:V ,
.BR add-scalar:V ,
.BR multiply-scalar:V ,
.BR square ,
.BR merge:FILE:POLICY
(POLICY in sum, max, keep),
.BR delete-node:N ,
.BR delete-nodes:N1,N2,.. ,
.BR isolate:N ,
.BR merge-nodes:N1,N2,..
(ties summed into the first name, the others removed),
.BR remove-outsiders ,
.BR renumber ,
.BR add-nodes:N ,
.BR clone-node:N
(a copy of the node with its ties, named "Clone of N").
.TP
.B draw IN \-\-out PNG [\-\-layout L] [\-\-size WxH] [\-\-labels] [\-\-background #rrggbb] [\-\-no-faces] [\-\-edge-values]
Render the network headlessly with the same visual language as the
desktop viewer.  Layouts: circular (default), random, spring, grid,
concentric.  Any canvas size is supported; a rectangular one is scaled
from the viewer's internal square.  \-\-labels draws node names,
\-\-background sets the canvas colour (and removes the default
background picture), \-\-no-faces hides the node faces,
\-\-edge-values draws tie values on the edges.  After rendering the
command prints the layout used and the assigned coordinates, one row
per node (index, name, x, y; percent coordinates).
.TP
.B generate \-\-nodes N \-\-out FILE [\-\-type T] [\-\-seed S] [\-\-degree D]
Generate a synthetic network.  Types: random (seeded Erdos\-Renyi,
average degree D, default 2), star (hub and ring), circular (edgeless
ring).  Seeded runs are fully reproducible.
.TP
.B matrix FILE [\-\-format csv|tsv] [\-\-out FILE]
Print the adjacency matrix, names in the header row and column.
.TP
.B nodes FILE [\-\-out FILE]
Print one row per node: index, name, out-degree, in-degree, x, y.
.TP
.B ego FILE \-\-node NAME \-\-out OUT
Extract the 1\-hop ego network of a named node (ties preserved, ego
laid out with the spring embedder).
.TP
.B components FILE
Print the connected components with their member lists.
.TP
.B metrics FILE [METRIC...] [\-\-all] [\-\-format csv|json] [\-\-out FILE]
Structured metrics in CSV or JSON (see METRICS below).
.TP
.B distance FILE \-\-from A \-\-to B
Print the shortest path between two named nodes (a geodesic of 0 means
no path).
.TP
.B diff A B [\-\-out FILE.csv]
Structural comparison by node names: added/removed nodes and per-pair
edge differences with both values.
.SH NETWORK COMMANDS
The following mirror the desktop's Network menu; each applies an
operation and saves a new file via
.BR \-\-out .
.TP
.B add-scalar FILE V \-\-out OUT
Add V to every cell.
.TP
.B multiply-scalar FILE V \-\-out OUT
Multiply every cell by V.
.TP
.B transpose FILE \-\-out OUT
Transpose the sociomatrix.
.TP
.B symmetrize FILE [\-\-mode below|sum|max] \-\-out OUT
Symmetrize the matrix (default mode below).
.TP
.B normalize FILE [\-\-binary | \-\-threshold V] \-\-out OUT
Binarize the matrix (default binary).
.TP
.B square FILE \-\-out OUT
Matrix square (walks of length 2).
.TP
.B merge-networks A B [\-\-mode sum|max|keep] \-\-out OUT
Merge two networks by node name (default mode sum).
.TP
.B remove-outsiders FILE \-\-out OUT
Delete every node with no ties.
.TP
.B delete-nodes FILE N1,N2,... \-\-out OUT
Delete the named nodes.
.TP
.B add-nodes FILE \-\-count N \-\-out OUT
Append N new nodes.
.TP
.B renumber FILE \-\-out OUT
Name the nodes 1..n.
.SH CHAIN, LAYOUT AND ATTRIBUTES
.TP
.B from-chain FILE \-\-out OUT
Create a network from a chain file (whitespace-separated sequences;
arcs follow the transitions between consecutive tokens), using the
engine's own chain reader - the desktop's "Create a network from a
chain file".
.TP
.B layout FILE \-\-layout L \-\-out OUT [\-\-size WxH]
Apply a layout to an existing network and save the new coordinates;
no image is rendered.  Layouts: circular, random, spring, grid,
concentric, star.  Output is byte-deterministic for the same seed.
.TP
.B set FILE \-\-out OUT [\-\-flag VALUE ...]
Edit the Network Viewer's image and edge properties of an existing
network file and save a new file.  The attributes are persisted in the
agn file itself.  Flags (run
.BR "agna set" " with no flags for the list")
include: \-\-name; \-\-names-visible on|off, \-\-names-x, \-\-names-y;
\-\-title-visible, \-\-title-x, \-\-title-y; \-\-grid-visible,
\-\-grid-step, \-\-grid-transparency, \-\-grid-color #rrggbb;
\-\-separator; \-\-max-transparency; \-\-edge-value-visible,
\-\-edge-value-position, \-\-edge-value-color; \-\-edge-color;
\-\-names-color; \-\-title-color; \-\-background-color;
\-\-background-image, \-\-background-image-x/y/width/height;
\-\-faces-visible; \-\-allow-edge-selection; \-\-color-fidelity;
\-\-snap-to-grid; \-\-default-face FILE (applies one face to every
node).  Colours are #rrggbb; quote them in the shell (an unquoted #
starts a comment).
.SH METRICS
Named metrics accepted by
.BR metrics :
density, diameter, eccentricity, closeness, betweenness, indegree,
outdegree, total-degree, emission, reception, status, determination,
geodesics.
With no names (or
.BR \-\-all )
every metric is produced.  Unknown names are rejected with exit code 1.
CSV layout: one uniform header \fBmetric,node1,node2,value\fR; scalar
metrics use empty node cells, node metrics one cell, geodesics both.
Values use four decimals and a locale-independent separator.  JSON is a
pretty-printed
.B {"network": ..., "metrics": [...]}
document.  Convention: a geodesic of 0 means no path; the
distance-based measures (diameter, eccentricity, closeness,
betweenness) are omitted, with a note, on disconnected networks.
.SH EXAMPLES
.nf
java -jar agna-cli-2.1.3.jar info samples/example2.agn
java -jar agna-cli-2.1.3.jar analyse samples/example2.agn --all
java -jar agna-cli-2.1.3.jar convert net.agn out.graphml
cat net.agn | java -jar agna-cli-2.1.3.jar convert - out.gml --in-format agn
java -jar agna-cli-2.1.3.jar transform in.agn out.agn --op merge-nodes:1,2
java -jar agna-cli-2.1.3.jar transform in.agn out.agn --op clone-node:Eve
java -jar agna-cli-2.1.3.jar draw in.agn --out net.png --layout spring --labels \\\\
    --background '#1a2332'
java -jar agna-cli-2.1.3.jar layout in.agn --layout concentric --out laid.agn
java -jar agna-cli-2.1.3.jar set in.agn --out styled.agn \\\\
    --names-visible on --edge-color '#e0b0ff'
java -jar agna-cli-2.1.3.jar from-chain sequences.txt --out chain.agn
java -jar agna-cli-2.1.3.jar generate --nodes 50 --type random --seed 7 --out r50.agn
java -jar agna-cli-2.1.3.jar metrics r50.agn betweenness closeness --format json
java -jar agna-cli-2.1.3.jar distance in.agn --from Alice --to Bob
java -jar agna-cli-2.1.3.jar diff a.agn b.agn --out diff.csv
.fi
.SH FILES
No configuration files are read by the CLI; the desktop application
keeps its own settings under
.IR ~/.agna/ .
