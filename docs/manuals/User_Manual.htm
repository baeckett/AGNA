1. Introduction

I begun working on the version 2 of this software in the second half of the year 2002, motivated by my constant interest in empirical areas of sociology. Still, Agna is the product of many years of sweat, curiosity and play.

The first versions (1995-2001) were DOS and Windows based and were being used only by me and a very small group of friends of mine. Then I rewrote the application in Java to make it compatible with any operating system. Thus, version 2.0 was the first one that I managed to distribute to the community of those interested in Social Network Analysis and Sequential Analysis.

Apart from having a number of bugs fixed, version 2.1 comes with a few improvements and changes, such as the node search utility, which was added to the visual network editor. For a complete list of these changes, please refer to the on-line News page. In developing this application, my main concern was to make it friendly, flexible, pleasant and widely accessible. I really hope that Agna will be helpful in your work, will rise further your desire for knowledge and will be a cheerful partner in your scientific plays. It is my wish that the future versions of this application have more menu options and run faster. As time and resources will be on my side, I will keep working.

I would also like to here from you and to have your comments on Agna. You are very welcome to e-mail imbenta@yahoo.co.uk.

Agna can run virtually on any computer that has the Java Virtual Machine (you can download JVM for free from http://java.sun.com/getjava/ or the JRE from http://java.sun.com/j2se/1.4/download.html). To install Agna on your computer, download the kit from the website https://www.netanalysis.co.uk and save it on your hard disk. 2. What Is Agna?

AGNA (Applied Graph & Network Analysis) is a platform-independent application designed for scientists and researchers who employ specific mathematical methods, such as social network analysis, sociometry and sequential analysis.

Specifically, Agna can assist in the study of communication relations in groups, organizational analysis and team building, kinship relations or animal behaviour laws of organization.

Agna 2 is a menu-driven application. It consists of two principal frames, each one having its own set of menus:

  • the Main Frame, which comprises a spreadsheet (a square matrix-grid) for entering and editing sociomatrix data on the left side of the screen and the Output Area (a very simple text editor) for receiving output information; this frame is automatically activated when launching the software

  • and the Network Viewer for visualizing and visually editing networks; this frame is by default inactive and can be opened up by selecting the View | View Network option from the Main Frame menu.

4. Data Management

You can enter and edit network data either directly in Main Frame's sociomatrix grid or using the visual network editor (the Network Viewer).

Agna will treat all sociomatrix data as real numbers. The decision whether a network is binary, weighted, directed or nondirected, will be made by the application at run time. For example, if you wish to compute the indegree coefficients in current network, Agna will decide whether the network contains weighted or binary data and will compute the suitable coefficients. In the first case, Agna will generate both the simple (binary) and the weighted versions of the indegree coefficient, whereas in the second case will compute only the simple indegree coefficients.

The diagonal cells of the spreadsheet are not editable, as Agna does not allow any node to be connected to itself.

When entering data using the spreadsheet, move the cursor using the arrow keys or by mouse-clicking on a specific grid cell and type a new value corresponding to an edge weight. You can make selections, copy, cut or paste ranges of data (eg, from a different application) in the spreadsheet.

By clicking a node label (the vertical header on the left of the sociomatrix spreadsheet), you can edit the name of that node. You can also rename all the nodes of the current network as numbers.

5. File Management

Agna deals with three types of files:

  • network data files (used to store and retrieve network data on/from your hard disk);

  • output files (text/HTML-files generated by Agna and containing analysis results);

  • image files (visual representations of networks generated by Agna).

Managing Network Data Files

The File menu allows you to

  • create a new empty network,

  • open an existing network from disk,

  • create a new network from a chain file, or

  • save the current network as a file.

At present, the following file formats are supported for storing/retreiving network data:

  • Agna Data Format (*.agn)

  • Comma Separated Values (*.csv)

  • Text tab-separated (*.txt, *.dat, *.text)




Agna Data File Format (*.agn)

AGN files are text files that contain full information about the networks created using Agna. They are automatically generated by the application at save time, but you can edit them manually as well.

The AGN file format itself does not fall under Agna's general Copyright (this means that other applications are free to export networks in this format).

This is the basic structure of an AGN file. As you can see, it consists of a list of elements, starting with the header Agna Data File (which is required). The list contains tags (both paired and unpaired tags) and values.

These elements are separated by TAB or LINE BREAK (actually, any combination of characters with ASCII code below 32 would do). For this reason, tags and values cannot contain TABs or LINE BREAKs. Blanc spaces are, however, allowed (for example, a node can be named Emile Durkheim).

Tags can be mentioned across the file anywhere and in any order you wish. The next element following an unpaired tag must always be its value. Paired tags usually enclose a list of elements, such as the list of node names.

Agna will tacitly ignore any text that is not a tag or is not obviously a tag value (such as: This is a fictional network in our example).

Please note that tag names are case sensitive!

There is virtually no limit as to the length of a value string.

Try now and open the file Sociologists.agn using Agna (File | Open Network) and check the names and the sociomatrix.

Tag name: Network Name

Value: Name of network, eg: Fathers of Sociology
Note: A string

Tag name: Network Size
Pair: --
Value: Size of network, eg: 3
Note: An integer value

Tag name: Has Viewer
Pair: --
Value: yes or no
Note: yes if file contains graphical information; no if file contains no graphical information

Tag name: Network Matrix
Pair: End Network Matrix
Value: A list of elements separated by TAB or LINE BREAK or combinations of them
Note: These elements represent the network's sociomatrix. Their number must be exactly g x g, where g is the value of the Network Size tag. They can be integer, real, positive or negative numbers. Diagonal elements must be 0 or Agna will tacitly set them to 0.

Pair: End Node Names
Value: A list of elements separated by TAB or LINE BREAK or combinations of them
Note: These elements are strings representing the network's node names. Their number must be exactly g, where g is the value of the Network Size tag.

Comma-separated Files (*.csv)

A CSV file will contain the sociomatrix plus the node names in the form of a matrix of g + 1 LINE-BREAK-separated rows, of g + 1 comma-separated values, where g is the number of nodes. The elements can be placed within quotation marks. The first element must be null.

Example

Open in a text editor the file Sociologists.csv, which is located in your Samples folder.

,Max Weber,Emile Durkheim,Karl Marx
Max Weber,0.0,1.0,1.0
Emile Durkheim,1.0,0.0,1.0
Karl Marx,1.0,1.0,0.0

As you can see, it represents a network of 3 actors whose names are Max Weber, Emile Durkheim and Karl Marx and which are all connected among them.




Text Tab-separated Files (*.txt, *.text, *.dat)

A text network file will contain the sociomatrix only, in the form of a list of g x g elements, where g is the number of nodes. The elements can be separated by TAB, LINE BREAK or any combination of these.

7. Analysing Data

All the analytic tools can be accessed through the Analysis menu in the Main Frame.

Basically, Agna can generate the following analyses:

  • general information (a Basic Description, some structural parameters: Diameter, Density, Cohesion)

  • information about the shortest paths in current network (Geodesic Matrix, Shortest Paths..., All Shortest Paths)

  • some node-level coefficients (four types of centrality coefficients and a few sociometric coefficients) together with their network-level aggregates and/or statistical descriptions

8. Visualizing Networks

To get a visual representation of the current network, simply choose View | Network Viewer from the Main Frame's menu.

A second frame will be activated, which will provide you with a simple network visual editor. You can save this image as a file on your hard disk, or insert it into your output file.

To customize the image, chose from the Image menu the command you wish: set the image width, scale the image, set the network layer (random vs. circular), change the title attributes of the image, specify the grid lines parameters, the node names, the background settings, the edge loyalty and the face settings for all nodes.

Here you can see the image of an eight-nodes network with green star faces, black background, edge loyalty and circular layout:

And now the same network using different settings: white background, different image width, random layout, blue triangle faces, no loyalty and edge values painted in green:

You can select a node by clicking inside its area (on its 'face'). To change the properties of the selected node, double-click it or chose from the Node menu the command you wish: set selected node's name, face, width and horizontal and vertical positions. You can also position your nodes on the screen by mouse drag-and-drop.

By default, clicking successively on two nodes will select an edge (if you don't need this and find it annoying, you can disable edge selection). The Edge menu allows you to set the connection value, the edge separation, edge color, the value of the most faded edge, the edge loyalty or the edge value position and color.

There are a few operations you can perform both in the sociomatrix editor (Main Frame) and the Network Viewer: adding nodes (double-click on the image outside a node area or by selecting Data | Add Nodes), removing outsiders, transposing network and symmetrizing network. Apart from these commands, the Network Viewer lets you clone, delete or isolate the currently selected node.

In large networks, finding a specific node is easy using the search tool located on a left panel:



To search for a node by name, type in the field the name or a fragment of a node name, then click Enter or press the search button. A list of results will be displayed. You can click on a node from that list and the corresponding node will be selected in the network. Double-click will show up the node settings dialog.

 Main Frame | File | New From Chain

Creates a new network from the dyadic transition matrix of the selected chain file.

A chain file must be a simple text file comprinsing a set of codes (ie, names of the basic behavioural units) separated by either TAB or LINE BREAK.

This operation will automatically close the Network Viewer, if open.

A short summary of the chain will be generated: the list of sequence codes identified in the file together with their frequencies and probabilities:

  • the frequency of a code counts how many times a code was found in the chain

  • the probability of a code is its frequency divided by the sum of all frequencies in the chain.

 Main Frame | Network | Symmetrize

Asks for the selection of a symmetrization criterion and converts current sociomatrix to a symmetrix matrix (and thus the current network to a non-directed network). Specifically, all paired elements (x[i,j] and x[j,i]) will be made equal according to one of the following criteria:

  • Maximum: the maximum value of the two will be chosen;

  • Minimum: the minimum value of the two will be chosen;

  • Maximum Non-Zero: the maximum value of the two will be chosen; if one of the elements is zero, the other one will be chosen;

  • Minimum Non-Zero: the minimum value of the two will be chosen; if one of the elements is zero, the other one will be chosen;

  • Below Diagonal: the element located below the sociomatrix' diagonal will be chosen;

  • Above Diagonal: the element located above the sociomatrix' diagonal will be chosen;

  • Below Diagonal Non-Zero: if non-zero, the element located below the sociomatrix' diagonal will be chosen; otherwise, the element located above the diagonal will replace both;

  • Above Diagonal Non-Zero: if non-zero, the element located above the sociomatrix' diagonal will be chosen; otherwise, the element located below the diagonal will replace both;

  • Sum: the arithmetical sum of the two paired elements will replace both (even if these elements were already equal);

  • Product: the arithmetical product of the two paired elements will replace both (even if these elements were already equal);

  • Product Non-Zero: the arithmetical product of the two paired elements will replace both (even if these elements were already equal); if one of the elements is zero, the other one will be chosen;

  • Arithmetical Mean: the arithmetical mean of the two paired elements will replace both.

  • Geometrical Mean: the geometrical mean of the two paired elements will replace both.

 Network Viewer | Data | Symmetrize

Asks for the selection of a symmetrization criterion and converts current sociomatrix to a symmetrix matrix (and thus the current network to a non-directed network). Specifically, all paired elements (x[i,j] and x[j,i]) will be made equal according to one of the following criteria:

  • Maximum: the maximum value of the two will be chosen;

  • Minimum: the minimum value of the two will be chosen;

  • Maximum Non-Zero: the maximum value of the two will be chosen; if one of the elements is zero, the other one will be chosen;

  • Minimum Non-Zero: the minimum value of the two will be chosen; if one of the elements is zero, the other one will be chosen;

  • Below Diagonal: the element located below the sociomatrix' diagonal will be chosen;

  • Above Diagonal: the element located above the sociomatrix' diagonal will be chosen;

  • Below Diagonal Non-Zero: if non-zero, the element located below the sociomatrix' diagonal will be chosen; otherwise, the element located above the diagonal will replace both;

  • Above Diagonal Non-Zero: if non-zero, the element located above the sociomatrix' diagonal will be chosen; otherwise, the element located below the diagonal will replace both;

  • Sum: the arithmetical sum of the two paired elements will replace both (even if these elements were already equal);

  • Product: the arithmetical product of the two paired elements will replace both (even if these elements were already equal);

  • Product Non-Zero: the arithmetical product of the two paired elements will replace both (even if these elements were already equal); if one of the elements is zero, the other one will be chosen;

  • Arithmetical Mean: the arithmetical mean of the two paired elements will replace both.

  • Geometrical Mean: the geometrical mean of the two paired elements will replace both.


This change will affect both the content of the visual network editor and the sociomatrix.

Please note that no undo option is available.

In the Main Frame, you can call this operation by choosing Network | Symmetrize.
